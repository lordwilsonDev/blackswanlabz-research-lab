# First Independent Use — From One Question to One Verified Result

**For:** anyone with a question and an AI assistant that can read GitHub. No degree, coding experience, paid subscription or full BlackSwanLabz install is needed to *begin*; some tasks may need tools, credentials or expertise to finish. This is a short entry point, **not a replacement** for the [full onboarding](using-with-your-ai.md) or the [50-question OS bootstrap](../08-operations/50-question-os-bootstrap-v1.md).

## What this is—and is not

The lab holds methods, sources and evidence records. This guide helps you apply an accessible part of it with your own AI. It does **not** install local-only components, open private files, turn a model answer into a proven discovery, replace professional licensing, or certify accuracy. A first result can be modest (a corrected spreadsheet, a reproducible calculation); pick something **bounded and low-risk** before any medical, legal, financial, physical or security matter.

## Start in five minutes

1. Give your AI the [lab URL](https://github.com/lordwilsonDev/blackswanlabz-research-lab) and the instruction below.
2. State **one problem you actually have** and what you could observe that would count as useful.
3. Ask for a result, a test and a receipt, not a congratulatory narrative. The protocol the AI follows is in the [AI-native version](first-independent-use.ai.md), written for the assistant to read.

### Copy and paste into Claude, Codex, Gemini or another capable assistant

```text
Act as my BlackSwanLabz first-use guide.

```

## Example scope

"Can I automate a recurring calculation in my small business?" A fair result is a script run on a sample CSV, checked against hand-calculated rows, with a repeatable command. Report it as **verified on the sample**, not "deployed."

## Longer processes

Organization-wide OS: [50-question onboarding](using-with-your-ai.md). Scientific claim: the [lab verification skill](../.claude/skills/lab-verify/SKILL.md). Reusable skill: [Skill Foundry](https://github.com/lordwilsonDev/blackswanlabz-skill-foundry).

## Share a result—without exposing yourself

Share a concise, reproducible account: what you asked, what you tried, what worked, what failed. Remove names, proprietary material, keys and personal records. Do not present generated hypotheses as discoveries. This guide does not promise a submission channel, support or independent reviewer.

**BlackSwanLabz's practical promise is access to a process for turning a question into a bounded, inspectable result—not a guarantee that every question has been solved.**
