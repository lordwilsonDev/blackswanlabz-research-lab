# BlackSwanLabz Workforce Grant OS v1

## Purpose

Treat workforce grants as downstream outputs of an evidence system, not documents to be written.

Core chain:

Employer Need -> Occupational Need -> Skills Gap -> Training -> Demonstrated Competency -> Employment/Advancement -> Wage/Retention Outcome -> Economic Impact -> Persistent Capacity

## Wisconsin reference case

The Wisconsin Fast Forward (WFF) Industry Sectors Worker Training Grant is an employer-oriented customized occupational training program. The current program requires an eligible applicant, employer participation, Wisconsin-based trainees, documented skills need, and a 50% cash or in-kind match. Eligibility and scoring are separate gates.

Wisconsin DWD also operates WisTRAIN, an employer-led workforce training program focused on advanced manufacturing and artificial intelligence, including AI/automation, data analytics, human-AI collaboration, and cybersecurity.

## Mandatory evidence objects

Every proposed program must maintain:

- applicant eligibility
- employer demand
- trainee eligibility
- occupational/SOC mapping
- baseline wage
- target/post-training wage
- placement/retention outcome
- employer commitment
- match
- training design
- competency assessments
- capacity-building plan
- funding-specific rubric

## Evidence states

VERIFIED, SUPPORTED, PROVISIONAL, INFERRED, UNKNOWN, CONTRADICTED.

Never promote a projection to an achieved outcome.

## Eligibility rule

Mandatory eligibility failure is BLOCKED, not a low score.

## BlackSwanLabz competency backbone

L1 Observe
L2 Retrieve
L3 Analyze
L4 Test
L5 Build
L6 Verify
L7 Design
L8 Orchestrate
L9 Create Reusable Capability
L10 Improve the Research System

These are competency levels, not occupational titles.

## Anti-consulting rule

Every funded activity must identify the occupational competency workers acquire and the test by which that competency is demonstrated. Consulting without worker skill acquisition is not counted as training.
