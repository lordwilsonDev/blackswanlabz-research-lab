# Workforce Grant Readiness Meta-SOP v1

## Purpose
Operate the Meta-Skill, Workforce Grant Skill, and harness as one governed system. The trainer must understand why each question exists, what uncertainty it resolves, what evidence can answer it, and what decision follows.

## Core chain
Employer Need -> Occupational Need -> Skills Gap -> Training -> Demonstrated Competency -> Employment/Retention/Advancement -> Wage/Productivity Outcome -> Employer Impact -> Persistent Capacity

## Operating loop
Ask -> Invert -> Verify -> Resolve -> Branch -> Preserve

## Before asking
1. Identify the decision.
2. Identify the dependency.
3. State the uncertainty.
4. Identify legitimate evidence.
5. State what would falsify the assumption.
6. Ask the smallest question that resolves it.

## MoIE inversion experts
Run independent passes for:
- eligibility
- employer need
- occupational mapping
- skills gap
- training effect
- competency
- outcomes
- wages
- employer commitment
- equity
- capacity
- evidence provenance
- cost/match
- anti-consulting
- model/vendor independence

Each expert must report:
- assumption
- inversion
- evidence required
- current evidence state
- failure mode
- unresolved dependency

Do not majority-vote the experts. Synthesize convergence, disagreement, missing evidence, high-leverage unknowns, contradictions, fatal dependencies, and repairable gaps.

## AIL procedure
For each important assumption:
1. State the axiom.
2. Invert it.
3. Generate competing explanations.
4. Identify discriminating evidence.
5. Verify before propagating the claim.

## Question provenance
Every material question records:
question_id, question, class, purpose, dependency, decision_unlocked, required_evidence, acceptable_evidence_state, negative_answer_consequence, next_action.

## Evidence states
VERIFIED | SUPPORTED | PROVISIONAL | INFERRED | UNKNOWN | CONTRADICTED

Downstream certainty cannot exceed prerequisite evidence.

## Anti-checklist rule
Do not ask a question merely because a form contains it. Prefer one question -> one dependency. No orphan questions.

## Missing-element sweep
After the first pass, ask:
"What important dependency does this system assume without testing?"

Attack missing:
worker voice, baseline, task analysis, trainer qualification, assessment reliability, accessibility, privacy, security, AI-use policy, human oversight, vendor dependency, credential recognition, transfer evidence, retention measurement, ownership, maintenance, audit trail, duplicate funding, change control, and failure escalation.

Only formalize a newly discovered requirement when governing rules or evidence justify it.

## Final trainer test
For every material question, the trainer must explain:
Why are we asking?
What uncertainty does it resolve?
What evidence can answer it?
What decision does it unlock?
What happens if the answer is wrong?

A trainer who can answer those questions is operating a governed workforce-development system rather than administering a questionnaire.
