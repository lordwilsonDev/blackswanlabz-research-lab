# Metric Contracts — Three-Process Learning Research Program v0.2

Every metric has a definition, unit, evidence requirement, and prohibited inference.

| Metric | Definition | Evidence | Do not infer |
|---|---|---|---|
| T_engage | Active effort until coherent engagement | Timestamped first valid engagement | Understanding |
| T_model | Active effort until adequate mechanism model | Evaluator-confirmed model | Mastery |
| T_architecture | Active effort until sufficient architecture | Artifact/record plus evaluator criterion | Correctness |
| T_first_build | Active effort until first executable artifact | Artifact plus timestamp | Correctness |
| T_functional | Active effort until requirements pass | Reproducible tests | Transfer |
| T_verified | Active effort until independent correctness verification | Independent verifier | Retention |
| T_transfer | Active effort until successful structural transfer | Fresh-task result | Broad expertise |
| T_retained | Epoch at which capability remains stable | Delayed fresh-task verification | Permanence |
| E_reference | Independently established historical active effort | Source or estimate record | Literal learning time |
| E_learner | Learner active effort to specified milestone | Run ledger | Intelligence |
| TCR | E_reference divided by E_learner | Both ledgers plus comparability check | IQ, superiority, or years of knowledge |
| L-level | Highest verified capability state | Level-specific A+B evidence | Credential equivalence |
| Q-level | Project-specific milestone state | Project-specific evidence | General capability |
| Terrain feature | Observed task-imposed demand | Learner/model array plus evidence | Intrinsic causality |
| Map divergence | Difference between independently produced maps | Preserved maps | Richness or error without analysis |
| Terrain stability | Persistence of feature set across epochs | Repeated maps | Truth of a feature |
| Reconstruction rate | Proportion of tested capability reproduced from stripped context | Hidden evaluation | Complete transfer |
| Assistance dependence | Performance change after assistance ablation | Registered ablation | Causation without design |
| Verifier defect rate | Material verifier errors per verification opportunity | Verifier audit log | Learner weakness |
| Failure class | Assigned category for a failed result | Failure-classification record | Causal certainty without adjudication |

## General rule

A metric is an observation. A scientific claim requires interpretation scope, evidence, and an uncertainty record.

## Verifier rule

A result cannot be interpreted as learner failure until verifier validity for that result has been established.
