# Learning Trajectory Research Program

This directory contains the versioned benchmark family for measuring learning as a trajectory from question to capability to build to verification.

## Benchmark family

- LTB-0.1 — Learning Trajectory Benchmark — measures demonstrated learner capability across L1–L5.
- INV-LTB-1 — Problem-Resistance Terrain Benchmark — measures terrain features imposed by a problem across an array of learners.
- Q2B-LTB-1 — Question-to-Build Learning Trajectory Benchmark — integrates problem terrain, capability trajectory, verified builds, transfer, retention, reconstruction, and reference-effort comparison.
- CRT-1 — Context Reconstruction Test — tests whether another model can reconstruct the research program from its evidence package.
- Metric contracts — normative definitions for timing, capability, terrain, transfer, verification, and trajectory compression.
- Run-record schema — machine-readable record contract.
- Change control — how benchmark definitions are versioned, amended, and preserved.
- Preregistration template — fixed study-registration fields.
- Benchmark selection — rules for choosing real long-horizon projects.

## Research position

These are research instruments, not claims that the instruments have already established the hypotheses they are designed to test.

The program distinguishes learner capability, problem terrain, artifact correctness, transfer and retention, historical reference effort, novelty/prior art, and context reconstruction.

## Three-process operating protocol

The core workflow is now frozen as:

1. INV-LTB — terrain characterization.
2. LTB — learner capability trajectory.
3. Q2B-LTB — integrated question-to-build analysis.

CRT-1 is the investigator reproducibility gate. See `protocol-0.1.md` and `readiness-gate.md`. The research program is currently HARD-STOPPED for new experimental runs until the remaining readiness items are resolved.

No single metric is treated as a universal measure of intelligence.

## Current state

Version family: 0.x research instrument.

The protocols are intentionally adjustable. Measurement-relevant changes must be versioned, dated, justified, and recorded rather than silently replacing earlier definitions.
