## Limits, as registered

- The standard is a rubric applied by a model judge. It is weaker than an executable check and measures what a judge rates as novel, which is not the same as what is novel or true.
- If a judge is the same model or family as the generator, self-preference bias can inflate ratings; the analysis flags a judge that used the same adapter, and the registered requirement is a different family.
- 12 author-written questions and 2 repetitions per question is a small sample. With 12 questions the registered rule has limited power to detect a modest effect (see controls.json).
- C5 (the retrieval-backed MoIE arm) and hypotheses H2 and H3 of the original package are not tested here; coherence non-inferiority is reported as a secondary check only.
- The Positive Deviant Scout uses the model's own knowledge, so cited anomalies are not verified and may be invented; the scout prompt asks the model not to invent cases.
- One generator model is tested. A result says nothing about other models.
- Blinding hides arm labels but not writing style; a judge may be able to guess which arm produced a text.
- The generator's context window must be large enough that MoIE's accumulated stage context is not truncated; the Ollama adapter is run with OLLAMA_NUM_CTX=8192 and fails closed if a prompt fills the window.
- Independence requirement not met: the generator and both judges are Claude models from one vendor, so shared training lineage and self-preference can inflate or distort ratings in an unknown direction.
- The claude CLI exposes no seed or temperature. Outputs are not exactly reproducible, and results come from one run.
- Token accounting excludes the CLI's fixed per-call scaffolding and estimates input tokens from characters; compute matching is therefore approximate.
- The run was executed and judged by an AI assistant in a cloud session at the owner's instruction, with generation and judging calls made automatically; the owner did not supervise individual calls.
- One generator model (Haiku) is tested. The result says nothing about other models, including the owner's local models.
- If interrupted, the run may be resumed with the same adapter; every resume is recorded in RUN.json.
