# Decision worksheet

A one-page aid for the person and the AI to fill in together at steps 2 to 4, and keep with the contract. The AI proposes an answer for each line and explains it; the person decides and changes anything.

**1. In my own words, I want:** (the exact words go in `source_utterance`)

**2. Working mode:** careful / fast (they chose, and saw the fast-mode warning)

**3. How much it matters**

| Question | Answer |
|---|---|
| Who is affected if it goes wrong? | only me / my team / customers or the public |
| Can the result be undone? | easily / partly / no |
| How sensitive is the data? | none / ordinary / personal or financial |
| How often does it run, and could that grow? | |
| Does anything leave my own account? | no / yes: what |

**4. The route (see `options-catalog.md`)**: chosen = ___ ; because ___ ; I considered the simpler options above it: yes / no

**5. What I will check before it runs for real** (tick which apply)
- [ ] first run is a dry run  - [ ] tested on a copy  - [ ] my own address as the only recipient
- [ ] the output shown to me before anything goes out  - [ ] I know how to stop it  - [ ] I know how to undo it

**6. What happens when it fails, and who finds out:** ___

**7. Owner, back-up person, review date:** ___

**8. What we do not know yet (goes in `missing_critical_facts`):** ___

**9. Deployment.** I will say, in my own words, when I want it deployed, and to which account: ___ (not filled in until then)
